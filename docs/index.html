Workshop_EstuaryFishSurvey

Estuary Fish Survey - Data Rescue Mission The Premise: You have inherited a project from a former PhD student who was studying the *relationship between water quality and predatory fish assemblages along the Ross River Estuary gradient. Unfortunately, their data management was entirely manual, and the files are a disaster. They left you with four separate datasets: - estuary_catch_log.xlsx: Handwritten field counts of fish species (using common names), spread across multiple spreadsheet tabs. - estuary_metadata.csv: The spatial coordinates and estuary zones for each site. - estuary_sonde_data.csv: High-frequency water quality sensor readings. - species_dictionary.csv: A taxonomic lookup table linking local common names to their accepted scientific names.

Task: Write a single, reproducible R script (or .qmd) that ingests this mess, cleans it, joins it into a single master dataset, and produces a publication-ready visualisation of the estuary’s ecology.

Introduction

The aim of this analysis is to rescue and combine four messy datasets from a study of the relationship between water quality and predatory fish assemblages along the Ross River Estuary gradient.

The workflow uses mainly tidyverse functions to:

  1. import and clean the fish catch data;
  2. standardise site and species names;
  3. join fish observations to the site metadata and taxonomic dictionary;
  4. clean and summarise the high-frequency sonde data;
  5. join water quality with fish observations; and
  6. produce a publication-ready visualisation.

The original data are not modified.

The site names use different combinations of spaces, underscores and capitalisation. First convert them to a consistent format.

Code 
metadata <- metadata |>
  mutate(
    site_name = str_to_lower(site_name),
    site_name = str_squish(site_name),
    site_name = str_replace_all(site_name, " ", "_"))

The site name can also be separated into two components and then recombined into a consistent site_key. This demonstrates separate() and unite() while making the standardisation explicit.

Code 
metadata_clean <- metadata |>
  separate(
    site_name,
    into = c("site_part1", "site_part2"),
    sep = "_",
    extra = "merge",
    fill = "right") |>
  mutate(
    site_part1 = str_squish(site_part1),
    site_part2 = str_squish(site_part2)) |>
  unite(
    site,
    site_part1,
    site_part2,
    sep = "_",
    remove = FALSE) |>
  select(
    site,
    lat,
    lon,
    zone) |>
  arrange(lat)

      variable == "salinity" & value < 0 ~ NA_real_,

    mean_abundance = mean(count, na.rm = TRUE),
    se_abundance = sd(count, na.rm = TRUE) /
      sqrt(sum(!is.na(count))),
    mean_salinity = mean(salinity, na.rm = TRUE),
    se_salinity = sd(salinity, na.rm = TRUE) /
      sqrt(sum(!is.na(salinity))),
    .groups = "drop")

write_csv(
  summary_table,
  here::here("output/summary_table.csv"))

Conclusion

The rescued dataset combines the original fish observations, taxonomic information, spatial metadata and daily water-quality measurements into a single reproducible dataset.

The main data-management steps were:

  • standardising inconsistent site and species names with mutate();
  • selecting and arranging relevant variables with select() and arrange();
  • removing incomplete records with drop_na();
  • separating and recombining site identifiers with separate() and unite();
  • reshaping high-frequency water-quality measurements with pivot_longer() and pivot_wider();
  • combining datasets with left_join(); and
  • summarising fish abundance and water quality with group_by() and summarise().

The final master dataset is saved as output/estuary_master_dataset.csv, and the publication-ready fish assemblage figure is saved in the output/ folder.
