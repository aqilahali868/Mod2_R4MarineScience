Introducing the Pipe |> (Base R) or %>% (Tidyverse, magrittr package)

#Logic of the Pipe |> - Without a pipe: read code “inside-out”. data in middle > mutate() > wrap using filter() > final wrap using select()

  • With a pipe: read code from left-right or top-bottom. data > filter > mutate to create new column > select columns needed

Instead of:

penguins_subset <- mutate(penguins, bill_ratio = bill_length_mm / bill_depth_mm)
penguins_final <- filter(penguins_subset, species == "Adelie")

Write:

penguins_final <- penguins |>
  mutate(bill_ration = bill_length_mm / bill_depth_mm) |>
  filter(species == "Adelie")
